# Process 8: ผ่อนชำระสินค้า

เข้าใช้งานจากหน้าแรก → **ผ่อนสินค้า** → **เพิ่มรายการผ่อน**

1. กรอกชื่อสินค้า ราคา เงินดาวน์ หมวดรายจ่าย จำนวนงวด และวันครบกำหนดงวดแรก
2. เลือกผ่อน 0% เพื่อคำนวณจากราคาหักเงินดาวน์ หรือระบุยอดต่องวดที่รวมดอกเบี้ย/ค่าธรรมเนียมตามสัญญาแล้ว
3. เลือกติดตามยอดอย่างเดียว เพิ่มเงินดาวน์เป็นรายจ่ายใหม่ หรือเชื่อมรายจ่ายเดิมที่ยอดตรงกัน (ล่าสุด 300 รายการ)
4. ตรวจสอบยอดรวม ยอดต่องวด และวันที่งวดสุดท้ายก่อนสร้างตาราง
5. เปิดรายการสินค้า เลือกงวด ระบุวันที่ชำระ แนบรูปหลักฐานได้ แล้วกดยืนยันเพื่อเพิ่มรายจ่าย
6. ชำระครบแล้วรายการจะย้ายไปแท็บ **ผ่อนครบแล้ว**

ตัวอย่าง: สินค้า 24,000 บาท ดาวน์ 4,000 บาท ผ่อน 0% จำนวน 10 งวด → งวดละ 2,000 บาท จ่ายหนึ่งงวดเหลือ 18,000 บาท

ระบบใช้จำนวนเต็มสตางค์เพื่อรักษายอดรวม กรณีหารไม่ลงตัวปรับเศษในงวดสุดท้าย วันที่ 29–31 จะใช้วันสุดท้ายของเดือนที่สั้นกว่า และกลับมาใช้วันเดิมในเดือนถัดไป

สถานะงวด: รอชำระ / เลยกำหนด / ชำระแล้ว ยอดเดือนนี้รวมเฉพาะงวดที่ยังไม่จ่ายและครบกำหนดในเดือนปัจจุบัน ยอดเลยกำหนดแสดงแยก ยอดจ่ายแล้วและความคืบหน้านับเฉพาะงวดผ่อน ไม่รวมเงินดาวน์

งวดละหนึ่งรายจ่าย ใช้ transaction และ row lock ป้องกันการกดจ่ายซ้ำ รายจ่ายที่มาจากผ่อนสินค้าและเงินดาวน์ที่เชื่อมไว้ไม่สามารถแก้หรือลบจากหน้ารายจ่ายได้ หากบันทึกงวดผิดให้ใช้ **ยกเลิกการบันทึก** ในหน้าตาราง ระบบคืนสถานะและนำรายจ่ายกับหลักฐานของงวดนั้นออก

เวอร์ชันนี้ชำระเต็มงวด รองรับงวดรายเดือน 1–360 งวด และวันที่ในช่วงปี 1900–2100 ไม่คำนวณอัตราดอกเบี้ย ลดต้นลดดอก ค่าปรับ หรือชำระบางส่วน ไม่ตัดเงินจริงจากบัญชี การแจ้งเลยกำหนดแสดงในแอป

## API

`GET installments`: ส่ง `id` เพื่ออ่านรายการเดียวได้ คืน `items` พร้อม `payments`, `next_payment`, `paid_count`, `paid_amount`, `remaining_amount`, `status` และ `summary` (`remaining`, `paid`, `due_this_month`, `overdue`, `active_count`)

`POST installments`:

```json
{
  "product_name": "โทรศัพท์มือถือ",
  "price": "24000.00",
  "down_payment": "4000.00",
  "installment_count": 10,
  "first_due_date": "2026-10-20",
  "category_id": null,
  "down_payment_mode": "record",
  "down_payment_date": "2026-10-13",
  "note": ""
}
```

ไม่ส่ง `monthly_amount` สำหรับ 0%; ส่งเป็นยอดต่องวดสำหรับยอดตามสัญญา ยอดรวมทุกงวดต้องไม่น้อยกว่าราคาหักดาวน์ `down_payment_mode`: `none`, `record`, `existing` (ต้องส่ง `down_transaction_id` ที่ยอดตรงกัน เป็นรายจ่าย manual/ai ของเจ้าของและยังไม่ได้เชื่อมรายการอื่น)

`POST installments/pay`: `payment_id`, `paid_date` แบบ JSON หรือ multipart ที่มี `proof` (JPEG/PNG/WebP ไม่เกิน 2 MB) วันที่ชำระต้องไม่เป็นอนาคต

`POST installments/unpay`: `payment_id` คืนสถานะรอชำระและลบรายจ่ายของงวด; หากยังไม่ชำระคืน 409

`GET installments/proof&id=PAYMENT_ID`: คืนภาพโดยตรวจบัญชีเจ้าของ

`DELETE installments&id=PLAN_ID`: ลบได้เมื่อไม่มีงวดที่ชำระและไม่มีเงินดาวน์เชื่อมรายจ่าย
